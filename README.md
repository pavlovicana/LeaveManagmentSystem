# 📝 Leave Management System

A web-based Leave Management System built using ASP.NET Core MVC and Razor Pages. This project is designed to practice and demonstrate full-stack web development skills using modern Microsoft technologies and industry best practices.

## 🚀 Project Overview

This application allows users to log in, manage leave requests, and perform various administrative tasks. It features secure authentication, clean architecture, and efficient data handling using a code-first approach with Entity Framework Core.

## 🧰 Technologies Used

### Backend
- ASP.NET Core MVC & Razor Pages
- C#
- Entity Framework Core (Code-First approach)
- Dependency Injection
- Authentication & Authorization

### Frontend
- Razor Pages
- Bootstrap 5

**Dev Tools & Services**
- Visual Studio 2022
- Git & GitHub
- Internet Information Services (IIS)
- Microsoft Azure (for cloud publishing)

**🔐 Features**

- User Registration and Login (Individual Accounts)
- Role-based access control
- Submit and approve leave requests
- Email notifications for requests and approvals
- Logging and monitoring for system events
- Clean architecture and coding best practices
- Local and cloud deployment support
